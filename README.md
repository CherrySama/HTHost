# Panthera Studio

独立运行的 Panthera HT 六轴机械臂网页仿真。MuJoCo WebAssembly 在浏览器内执行物理计算，Three.js 根据 MuJoCo 的几何体世界坐标绘制模型。采用浅色工作区与简洁的关节控制面板。

## 启动

需要 Node.js 22 或更高版本。首次运行：

```bash
cd ~/Desktop/HTHost
npm ci
npm run dev
```

打开终端显示的地址，默认是 http://localhost:5173 。模型和 WASM 由本地服务提供，运行时不需要访问 CDN，也不需要 Python、ROS 或真机。

## 操作

- 拖动 J1–J6 滑条调整目标角度，或在输入框填写角度后按 Enter / 移出焦点确认。输入、实际值、限位及内部计算统一使用弧度（rad），控件步长为 `0.01 rad`。
- 调整关节时，对应连杆呈现淡蓝色高亮。拖动期间保持提示，松开或提交角度后约 0.8 秒淡出；切换关节立即转移提示，复位清除提示。高亮只改变外观，不影响物理模型。
- 每个关节右上角显示仿真实际角度。目标通过力矩 PD 控制和偏置力补偿驱动，不直接覆盖关节状态。
- 夹爪支持电机目标 `0–2 rad`、张开/闭合按钮，并分别显示目标总开口和实际总开口（mm）。`0 rad` 对应闭合，`2 rad` 对应 82 mm，左右各移动 41 mm。仿真启动和复位时夹爪均闭合。
- 夹爪按用户提供的“电机角度与夹爪行程对照表”逐点分段线性插值，加上确认的 `(0 rad, 0 mm)` 端点；不使用带非零截距的三次式外推。`0–0.25 rad` 区间仅有端点约束，没有额外实测点；SDK 更宽的角度范围未纳入当前仿真控制。
- 鼠标拖动旋转视角，滚轮缩放，右键平移；底部按钮恢复视角、切换网格。
- “全部复位”让六轴回零并闭合夹爪。关节控制标题旁的“末端拖拽”可打开绿色手柄，按住 Shift 拖动可调整深度。
- 在右侧切换到“电机监控”，选择 J1–J6，查看目标/实际位置（rad）、速度（rad/s）、执行器力矩（N·m）和有符号的位置误差（目标 − 实际，rad）。控制与监控面板也可通过左右方向键切换。
- 曲线保留最近 15 秒仿真时间内、至多 151 组数据，采样频率最高约 10 Hz。后台也记录未选中关节，切换关节保留历史，复位清空历史。
- 监控面板明确标注“仿真数据”。力矩来自 MuJoCo 的 `qfrc_actuator`，包含控制器的补偿输出，不是实测接触力，也不是已接入的真机反馈；当前不显示没有反馈来源的电流、温度、电压和故障状态。

## 模型及边界

模型资产位于 `Panthera-HT_SDK/panthera_python/Panthera-HT_description_V1.1.0`。外观网格从 SDK 加载，Host 使用派生的 `models/panthera.xml` 和独立凸碰撞分片启用物理自碰撞，保留外观配色、惯性、重力、地面接触及关节限位。SDK 源文件未修改。

六个关节通过原模型的力矩执行器控制，遵守其力矩限幅和目标角度范围。PD 参数是展示用参数，未经过真机标定；受限位软约束和接触影响，实际角度可能存在偏差，控制器不会保证任意姿态立即到达。

限位直接读取当前 MuJoCo 模型的 `jnt_range`，不套用旧版上位机 YAML。当前资产的 `config/` YAML 仅包含关节名称。界面显示模型的上下限；滑条的端点向范围内取整到 `0.01 rad`，保证步进从零对齐，数值输入仍按模型的精确上下限裁剪。

Host 为左右夹指启用对称直线关节和物理控制，启用非相邻连杆之间的自碰撞物理阻挡。目标角度可能因碰撞无法达到，界面分别保留目标值和实际值，接触时显示状态提示。反向调整目标可退出接触；不会通过瞬移关节位置来回避碰撞。仿真复位将机械臂关节清零，并将夹爪闭合。

Host 默认显示 SDK 中可选的 D405 腕部相机及安装支架，按源 URDF 的 `camera_joint` 固定连接到 `link6`。相机随腕部运动，保留资产定义的 0.08 kg 质量和惯性，并参与物理碰撞；SDK 中原本被注释的相机定义保持原样。

当前未提供相机 RGB/深度图像、抓取任务、真机控制或路径避障规划。碰撞几何是近似分片，MuJoCo 接触也是软约束，此页面不能用于验证真机运动安全。模型生成方式与排除关系见 [models/README.md](models/README.md)。SDK 目前作为模型资产依赖，尚未调用硬件接口。

首次加载需读取约 64 MB 网格及 11 MB WASM，加载期间显示进度。静止时按需重绘，移动时更新姿态；高精度原始网格在低性能设备或软件渲染环境下可能较慢。

## 构建与验证

```bash
npm run build
npm run preview
npm test
```

生产预览默认使用 http://localhost:4173 。自动化测试使用本机 `/usr/bin/google-chrome`，其他安装路径可通过 `CHROME_PATH` 指定。测试覆盖六个关节独立跟随、目标限幅、复位、网格开关、移动端水平布局，以及 J4 折叠时自碰撞阻挡和反向脱离。`python3 scripts/check_collision.py` 另可检查原生 MuJoCo 的接触力与穿透。

## 代码入口

- `src/simulation.js`：加载本地 WASM 与 MJCF、固定步长仿真、六轴控制。
- `src/viewer.js`：从 MuJoCo 编译后的网格与几何体变换构建 Three.js 画面。
- `src/main.js`：控制面板、状态展示与事件连接。
- `src/motor-telemetry.js`：单关节监控、历史采样及 Canvas 曲线。
- `src/style.css`：桌面与移动端界面。

MuJoCo 官方 JavaScript 绑定说明：https://github.com/google-deepmind/mujoco/tree/main/wasm
